# Projeto de Machine Learning 

## Visão Geral

Este projeto foi desenvolvido como parte dos nossos estudos acadêmicos na faculdade, pelo Grupo ZUP. O objetivo do projeto é realizar chamadas a uma API, receber respostas e analisá-las utilizando bibliotecas de Machine Learning.

## Funcionalidades

- Realiza chamadas a uma API desenvolvida pelo Grupo ZUP.
- Recebe respostas da API.
- Analisa as respostas utilizando uma massa de strings com técnicas de Machine Learning.

## Tecnologias Utilizadas

- Python
- API desenvolvida pelo Grupo ZUP

## Bibliotecas: 

- jupyterlab
- notebook
- pandas
- sklearn
- seaborn

## Como Utilizar

1. Clone o repositório

2. Execute na raiz:
   ```bash
    python -m venv virt
    source virt/scripts/activate
    ```

4. Instale as dependências:
    ```bash
    pip install jupyterlab
    pip install notebook
    pip install pandas
    pip install sklearn
    pip install seaborn
    pip install -U scikit-learn
    pip install --upgrade scikit-learn==0.18.0
    ```
5. Executar o JupyterLab:
   ```bash
    jupyter notebook
    ```
